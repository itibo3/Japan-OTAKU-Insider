Details (EN)

Independent game developer Yamato Nadeshiko has released a demo version of “Janfuda,” a competitive game that combines mahjong and card battles. A key feature of the game is the ability to change the course of play using card effects—such as disabling “ron” or specifying which tiles an opponent must discard. Players can enjoy the game via a browser on a PC or smartphone without needing to register.
