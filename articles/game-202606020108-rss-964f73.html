The 2D platformer "ProjectDevourSlime" has announced that it will release a trial version on Steam on June 3, 2026. This work is a 2D platform game in which you conquer stages while absorbing and ejecting scaffolding. Scaffolding is a limited resource, so players must consider where to absorb it and where to use it while constructing their own clear route.
