Let's introduce BanjihaGames' new PC game ``The Ninth Record,'' which was exhibited at the Korean indie game event ``BIC2026.'' This is a mystery ADV with an unusual system in which you search the blackened investigation records using words and reconstruct the hit pieces to deduce the truth of the case. Release is scheduled for 2027.
