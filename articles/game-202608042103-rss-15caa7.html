Ludit has released the Steam store page for the action game ``DarkCastle'' released for Macintosh in 1986 and its sequel ``BeyondDarkCastle.'' Both titles are faithful reproductions of the original versions using Indigo Runtime, which reimplements the Mac environment of the time. Both are scheduled to be released in 2026.
