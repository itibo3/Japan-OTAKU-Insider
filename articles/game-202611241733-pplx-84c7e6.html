Details (EN)

Koei Tecmo Games announced that it will release the second paid DLC for *Nioh 3*, titled “The Amakusa Uprising,” on December 17, 2026. Set in Shimabara in 1638, the DLC features characters such as Shiro Amakusa and Muneshige Tachibana, bringing the story that began in the first DLC to a conclusion. The “Complete Edition,” which includes the main game and both DLCs, will also be released on January 28, 2027.
