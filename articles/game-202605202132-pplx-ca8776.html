Digital Bandidos and CRYING BRICK have announced that they have released the latest update for the survival roguelike game ``Froggy Hates Snow.'' This update includes the addition of a temporary save function that does not affect the game balance based on player feedback, and an option to shorten wave arrival time for advanced players.
