Details (EN)

Bside released a major update (Ver. 1.2.0) for the 3D puzzle game “NAMCOLEGENDARYMountains” today. New competitive features have been added, including “Score Attack,” where players compete to achieve the highest score within a time limit, and “Voxel Race,” where players race to create the largest voxel before their opponent. The game also supports solo practice mode.
