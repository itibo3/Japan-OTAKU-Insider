Details (EN)

Hamster announced today that it will release “Console Archives Chackun Pop” on October 1, 2026. This title is a re-release of the action game “Chackun Pop,” originally released by Taito in 1985. Players navigate the maze by mastering techniques such as the “U-Turn Technique,” which allows them to run along walls and ceilings, and the “Fireworks Technique,” which simultaneously detonates bombs.
