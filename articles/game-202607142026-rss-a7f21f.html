Details (EN)

Yanoman and Nippon Art Media today announced that crowdfunding for the ``Aretha Reunion Project ~I Want to See You Again~'' will begin at 21:00 on July 15, 2026. This project aims to revive the RPG "Aretha" series, which was developed for the Super Famicom and Game Boy versions, and the application period is until 23:59 on August 31st.
