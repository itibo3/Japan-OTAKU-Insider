Details (EN)

Microsoft announced today (September 4, 2026) that it will change the way it offers “Xbox Cloud Gaming” starting in November. After the change, each Xbox Game Pass plan will include a set amount of “cloud play time” per month, and users will be able to use the service within that limit. In addition, a new option will be introduced that allows users to access Xbox Cloud Gaming without subscribing to Game Pass.
