Details (EN)

Marvelous announced today (September 10, 2026) that it will release the lavish, Japanese-style action RPG *Oboro Muramasa: Kaiki-tan* on February 4, 2027. The PC (Steam) version is scheduled for release on February 5 via Marvelous USA. This title combines the PS Vita game “Oboro Muramasa” with the DLC “Genroku Kaiki-tan” into a single package, featuring upgraded high-resolution graphics and new content.
