Wataritama Studio announced today that it will release the PC game “Going Viral in the Past: If I Start as a VTuber in 2018, Maybe I’ll Go Viral!?” on Steam sometime in 2026, and has unveiled the game’s Steam store page. This game is a simulation in which players rewind time to the year 2018 and build a VTuber from zero subscribers to viral stardom.
