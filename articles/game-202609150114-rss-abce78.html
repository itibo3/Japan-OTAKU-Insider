Details (EN)

HoYoverse announced today (September 14, 2026) that it will stream the preview program for Version 4.6 of the space fantasy RPG *Honkai: Star Rail*, titled “Dance with the Beast Before the Moon Rises,” starting at 8:30 p.m. on September 20. The program will feature information on Pearl (voiced by Kiyono Yasuno), who will be introduced as a new playable character, as well as the latest updates on Version 4.6 and bonus content.
